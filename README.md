# 🚀 Real-World Project

## PAUD/MDTA Babussalam Administrative Management System

**KKN · Real-World Digitalization Project**

Designed and developed a web-based administrative management system for **PAUD/MDTA Babussalam Foundation** to replace previously manual administrative processes with a centralized and automated digital system.

### The Problem

Before the system was developed, administrative records and document preparation were handled manually.

This created challenges in:

- Searching and managing student records
- Recording new student data
- Preparing administrative reports
- Generating certificates
- Maintaining organized and accessible records

As the number of students continues to grow, a more structured administrative system was needed.

### The Solution

I developed a centralized web-based system that integrates **student data management, dashboard monitoring, automated reporting, certificate generation, and user guidance** into a single platform.

### Key Features

| Module | Function |
| :--- | :--- |
| 📊 **Dashboard** | Provides an overview of student and administrative data |
| 🔎 **Data Management & Search** | Enables faster searching and management of student records |
| 📝 **Student Data Input** | Provides a structured interface for recording student information |
| 📄 **Automated Reports** | Generates administrative reports in **PDF and Excel** formats |
| 🏆 **Automated Certificates** | Generates certificates based on stored student data |
| 📚 **User Guide** | Provides text-based instructions for using the system |
| 🎥 **Video Tutorial** | Provides step-by-step guidance through video tutorials |

### Project Scale

| Metric | Current Status |
| :--- | :--- |
| 👨‍🎓 **Student Records** | **192 students** |
| 🏫 **Institution** | PAUD/MDTA Babussalam Foundation |
| 🔄 **System Status** | **Actively used** |
| 📈 **Future Growth** | Student records will continue to increase with new academic years |

### My Contribution

- Identified administrative processes that could be digitized and automated.
- Designed the structure of the administrative workflow and data management process.
- Developed the web-based administrative system.
- Implemented student data input and search functionality.
- Developed the administrative dashboard.
- Implemented automated report generation in PDF and Excel formats.
- Implemented automated certificate generation.
- Created text and video tutorials to support system adoption.
- Maintained the system for continued use as new student data is added.
